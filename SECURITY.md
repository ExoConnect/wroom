# Security Policy

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub private vulnerability
reporting](https://github.com/ExoConnect/wroom/security/advisories/new).
Please do not open a public issue.

Include the affected commit, a repro or packet capture where possible,
and your assessment of impact.

## Scope and support

wroom is pre-release software — there are no supported versions yet.
Fixes land on `main`; running anything older is at your own risk.

We aim to acknowledge reports within 72 hours.
